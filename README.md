JAVA BANKING SYSTEM CREATED ON 25 OCTOBER 2024.

This project consists of two files: ATMAccount.java and the Main.java.
I used objects and classes in Java to implement this system, where ATMAccount.java implements the class and object of the system and Main.Java creates account objects and execute them.
I am still working on to improve it.

Now, this project runs on the console, so you need a Java Runtime Environment (JRE) installed on your machine for you to run the project.
A JRE is a software program that allows you to run Java applications without any need for an IDE.
It can be downloaded and installed separately from an IDE, but IDEs such as eclipse and others have it preinstalled for your convenience.
